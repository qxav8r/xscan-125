xScan-125

Program a Uniden BC125AT scanner from your Mac

early preview v0.1 · free & open source (MIT)
Download xScan-125 The Mac stack: Scanner Info, Read Banks, Export / Import Channels and Settings, all point and click.
Latest release Channel Editor Edit your banks and frequencies in the browser, sort and renumber, then save a CSV for Import Channels. Nothing is uploaded.
Open the Editor

What it does

InitializeChecks Homebrew, libusb and bc125at-tool, then talks to the scanner. The other buttons stay off until every check passes.
Scanner InfoModel, firmware, what's on the display, current settings, which banks are on.
Read BanksSaves every programmed channel to a CSV and opens a channel report in your browser.
Export / ImportBack up all channels to a CSV, or write a CSV to the scanner.
SettingsVolume, squelch, contrast, backlight, priority and more, read back from the scanner to confirm.
Load Presets, Manage BanksComing soon.

Editing channels: Export Channels → Channel Editor → Save CSV → Import Channels.

What you need

  • A Mac on Apple Silicon (tested). Intel Macs should work but aren't tested yet.
  • A free xTalk app to open the stack. xScan-125 runs inside one; it isn't a double-click app. HyperXTalk is recommended (built and tested in 0.9.15); OpenXTalk or LiveCode should work.
  • Homebrew and libusb: brew install libusb
  • bc125at-tool, set up once with its ./setup.sh

The Channel Editor needs none of this. It runs in any browser, including an iPad.

Quick start

  1. Install HyperXTalk.
  2. Install Homebrew, then brew install libusb.
  3. Download bc125at-tool into your home folder and run ./setup.sh in it.
  4. Plug in the scanner (USB) and turn it on.
  5. Open the xScan-125 stack in HyperXTalk and click Initialize.
