xScan-125 WebUSB Probe

Read-only test: can a web page talk to a Uniden BC125AT? (Chrome or Edge on a desktop.)

Not connected




Sends only MDL and VER. Nothing is written to the scanner.

Expected replies: MDL,BC125AT and VER,Version 1.xx.xx.

Commands per Uniden's BC125AT PC Protocol (docs/reference). Uniden vendor ID 0x1965.

If "WebUSB not available": open this page from http://localhost (in Terminal:
cd to this folder, run python3 -m http.server, then open
http://localhost:8000/webusb-probe.html).
