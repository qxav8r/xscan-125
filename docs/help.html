xScan-125 Help

Program a Uniden BC125AT scanner from your Mac. An OpenXTalk / xTalk-family stack (HyperXTalk, OpenXTalk, LiveCode).

xScan-125 on GitHub bc125at-tool

Getting started

xScan-125 is the front end. The talking to the scanner is done by bc125at-tool, which you install once.

xScan-125 is a stack, not a standalone app — it runs inside a free xTalk development app (IDE).

  1. HyperXTalk — install it from GitHub (free, macOS 13 or later). xScan-125 is built and tested in HyperXTalk; OpenXTalk or LiveCode should also work but aren't tested yet.
  2. Homebrew — install from brew.sh if you don't have it.
  3. libusb — in Terminal: brew install libusb
  4. bc125at-tool — download it from GitHub (put it in your home folder), then in Terminal: 
    cd ~/bc125at-tool
./setup.sh
  5. Plug in the scanner with its USB cable and turn it on.
  6. Open the xScan-125 stack in HyperXTalk and click Initialize.

Initialize

The scanner buttons stay greyed out until Initialize passes. Every time you open the stack, click Initialize first. It checks:

CheckIf it fails
HomebrewInstall from brew.sh
libusbbrew install libusb
bc125at-tool folderFound automatically (see below), or you're asked to pick it
Python environmentRun ./setup.sh inside the bc125at-tool folder
ScannerCheck power and cable, then click Initialize again

When everything shows ✓ you'll see Ready. and the scanner buttons turn on.

How the bc125at-tool folder is found

On every Initialize, xScan-125 looks in the usual places — your home folder, Documents, Desktop, Downloads, Documents/GitHub and the folder next to the stack — then asks Spotlight for any folder named bc125at-tool… (including bc125at-tool-main from a ZIP download). A folder only counts once ./setup.sh has been run in it.

Trade-off: the folder isn't remembered between sessions. If you keep it somewhere unusual, under a name Spotlight won't match, you'll be asked to pick it each time. Keeping it in your home folder as bc125at-tool avoids that.

Settings

The Settings palette reads the scanner when it opens, so it always starts from what the scanner really has. Change what you like and click Apply: only the changed settings are sent, then the scanner is read back and each change is marked ✓ kept or ⚠ not kept in the main window. The palette stays open and shows the scanner's real values. Read Scanner re-reads at any time; Close (or Esc) closes it.

Weather alert turns itself off

Weather alert only stays on when the scanner can hear a NOAA weather station. If it can't, the scanner turns it back off by itself and briefly shows No WX Reception — that's the scanner's own design (see the BC125AT manual, Weather Alert Priority), so xScan-125 reports it as ⚠ not kept. Check reception with the scanner's WX key, raise the antenna or move near a window, then try again.

Editing channels

There's no channel editor in the stack yet. The easy way is a round trip:

  1. Export Channels to a CSV file.
  2. Open the CSV in Numbers or Excel, edit names, frequencies, banks — then save it as CSV.
  3. Import Channels and pick the edited file.

Columns: channel, name, frequency, modulation, tone, tone_code, delay, lockout, priority, bank. Names are cut to 16 characters by the scanner.

Banks and channels

The BC125AT has 500 channels in 10 banks of 50. Bank 1 is channels 1–50, bank 2 is 51–100 … bank 9 is 401–450, and the tenth bank — shown as 0 on the scanner — is channels 451–500.

Troubleshooting

  • Scanner not responding right after plugging in — click Initialize again; the first try sometimes misses.
  • Only one program at a time can talk to the scanner. Close other scanner apps or Terminal sessions using bc125at-tool.
  • Odd characters in raw scanner output are the scanner's display icons (signal, battery) — harmless.
